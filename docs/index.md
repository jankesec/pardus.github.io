# Welcome to Pardus

**Rock-Solid & Modern Ecosystem**

Pardus is a based on Debian GNU/Linux distribution engineered to bridge the gap between stability and rich application availability. Built on a proven architecture, it offers a crash-free experience without sacrificing access to the tools you need.

[Download Pardus](download.md){ .md-button .md-button--primary } [Join the Community](https://github.com/pardus){ .md-button }

---

<h2>Why Pardus?</h2>

Pardus is free to download and install. We are committed to open source, including non-free firmware only where necessary for hardware compatibility.

*   **Stability**
    Experience a system designed to work consistently, day in and day out. No crashes, no instability. Just a reliable environment for you.

*   **Modern Pardus Store**
    A stable core with an extensive application library. Install a wide range of modern development tools and applications with a single click directly from our repositories.

*   **Extensive Package Maintenance**
    We actively maintain and track packages to ensure seamless integration and security. You can verify our work and package status at [tracker.pardus.org.tr](https://tracker.pardus.org.tr).

*   **Productivity First**
    No bloat, no unnecessary "show". Just a clean, fast, and efficient environment optimized for developers and power users.
